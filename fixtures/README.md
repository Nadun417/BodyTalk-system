# Test footage

This folder holds the practice-interview recordings used to develop and test BodyTalk.

The recordings never leave this machine. Video files, and everything derived from them, such as the
cached landmark data and saved analysis sessions, are excluded from version control because they show
real people.

When a recording here is analysed, its detected landmarks are cached in `landmarks/` beside it, so the
slow detection step only has to run once for each video.
